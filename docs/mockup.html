Navigator

Five Jive trees, one navigator

Hosts, servers, devices, classes, aliases and free properties are scopes of the same tree, lazily loaded and filtered in place. Ctrl K resolves any name, alias or tango:// URI.

Live data

Events, with the fallback visible

Values arrive by Tango change events. Where events are unavailable the value is polled and marked with a dotted underline, so nobody mistakes a stale reading for a pushed one.

Writes

Preview, apply, undo

Every database edit is a command: diffed before it is written, logged in the journal with the previous value, and reversible. Read-only mode is one wrapper around the backend.

Process control

Startup levels as lanes

A host is its startup sequence, so the host panel is grouped by level rather than alphabetically. Bulk actions operate level by level, in order, the way Starter does.
